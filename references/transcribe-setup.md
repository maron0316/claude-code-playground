# 文字起こしの道具（MLX Whisper）の準備と使い方

動画の音声を文字にする道具。Apple シリコン（M1 以降）の Mac の GPU を使い、**音声・動画をインターネットに送らずに、この Mac の中だけで**文字にする。
テロップの原稿づくり・字幕ファイル（.srt）づくり・カットする場所さがしに使う。

- 中身: Apple の MLX 版 Whisper（`mlx-whisper`）と、モデル `mlx-community/whisper-large-v3-turbo`（約1.6GB）
- 入れる場所: `~/.my-video-editor/mlx-whisper/`（専用の場所。ほかの場所は変えない）
- 道具: `scripts/transcribe.py`（このスキルのフォルダの中）。**自分（AI）が実行する。本人にターミナルを打たせない。**
- 出典: Apple MLX Whisper https://github.com/ml-explore/mlx-examples/tree/main/whisper ／ モデル https://huggingface.co/mlx-community/whisper-large-v3-turbo

## 1. 調べる（何も変えない）

```text
python3 <このスキルのフォルダ>/scripts/transcribe.py check
```

結果の「判定」をかんたんな言葉で本人に伝える。

| 判定 | 本人に伝えること・次にすること |
|---|---|
| すぐに文字起こしできます | 「もう入っています」と伝えて終わり |
| 入れられます | 下の「2. 入れる」へ |
| 先に Python を入れる必要があります | 下の「Python が無いとき」へ |
| このパソコンでは使えません | 「この道具は M1 以降の Mac だけで動きます。文字起こしは使わずに進めます」と伝えて、ほかの準備を続ける |
| 空き容量が足りないかもしれません | 空きを作るかどうか、本人に決めてもらう。勝手にファイルを消さない |

`python3` が無い・Mac が「コマンドライン・デベロッパ・ツールをインストールしますか」と聞いてきたときは、押す前に本人に「Mac の開発用の道具を入れるかの確認です。入れる場合は『インストール』を押してください（数分〜十数分かかります）」と説明する。

## 2. 入れる（本人の OK が必要）

入れる前に、本人にこう聞いて OK をもらう:

> 動画の音声を文字にする道具（MLX Whisper）を入れてもよいですか？
> ・場所: あなたのホームフォルダの中の、専用のフォルダ（.my-video-editor）
> ・大きさ: 合わせて約3GB（道具が約1.3GB、文字起こしのモデルが約1.6GB）
> ・時間: 道具は数分。モデルは、はじめて文字起こしをするときにダウンロードします
> ・音声や動画はインターネットに送りません。この Mac の中だけで文字にします

OK が出たら:

```text
python3 <このスキルのフォルダ>/scripts/transcribe.py setup --yes
```

- 「許可しますか」の画面が出るときは、出る前に「道具を入れるためのコマンドです。よければ許可を押してください」と伝える。
- 終わったら、本人のテスト用の短い動画（または `say` で作った短い音声）で「3. 使う」を一度試し、できた文字を見せる。
- `my-environment.md` の「文字起こし」の欄に「MLX Whisper：入れた（日付）」と書く。

## Python が無いとき（本人にやってもらう）

MLX は **Python 3.10 以上**が必要。Mac に最初から入っている Python（3.9）では動かない。
本人に、次の手順で入れてもらう。**パスワードの入力は本人が行う。自分は入力しない。**

1. ブラウザで https://www.python.org/downloads/macos/ を開く
2. いちばん上の「Latest Python 3 Release」を押し、ページの下のほうの **macOS 64-bit universal2 installer** を押してダウンロードする
3. ダウンロードした `.pkg` をダブルクリックして、画面の案内どおりに「続ける」「同意する」「インストール」を押す（Mac のパスワードを聞かれたら、本人が入れる）
4. 終わったら、もう一度 `check` を実行する

## 3. 使う（文字起こし）

```text
python3 <このスキルのフォルダ>/scripts/transcribe.py run "<動画か音声のファイル>" --language ja --out "<保存先フォルダ>"
```

- 保存先は本人に聞いて決める（`my-environment.md` にあればそれを使う）。`--out` を付けないと `~/.my-video-editor/transcripts/` に入る。
- 元の動画・音声は読むだけ。動かさない・上書きしない。
- できるもの: `.txt`（読むための全文）／`.srt` と `.vtt`（字幕）／`.json`（時刻つきの生データ）／`.tsv`
- 日本語なら `--language ja`、英語なら `--language en`。わからなければ付けない（自動で判定する）。
- **自動の文字起こしは完成原稿ではない。** 人の名前・商品名・数字・専門用語（例: 「AI」が「愛」になる）はまちがえやすい。テロップに使う前に、まちがえやすい所を本人に見せて確かめてもらう。
- 長い動画は時間がかかる。はじめる前に、だいたいの時間を伝える。

## Windows のとき

MLX Whisper は Apple シリコンの Mac 専用なので、Windows では使えない（`scripts/transcribe.py` も Mac 用）。
Windows では、次のように進める。**キットの作者は Windows での動作を確かめていない。**

1. 本人に「Windows なので、この道具（MLX Whisper）は使えません。かわりに、同じようにパソコンの中だけで文字起こしができる道具（faster-whisper）を入れる方法がありますが、入れますか？」と聞く。
2. 入れるときは、入れる場所（例: `%USERPROFILE%\.my-video-editor\whisper\`）・大きさ・時間を伝えて OK をもらい、その専用の場所に Python の仮想環境を作って入れる。Python が無ければ、python.org の Windows 用インストーラーを本人に入れてもらう（「Add python.exe to PATH」にチェックを入れてもらう）。
3. 入れ方・使い方は、faster-whisper の公式（https://github.com/SYSTRAN/faster-whisper ）を読んで確かめてから行う。覚えている知識だけで進めない。
4. うまくいかないとき・入れないときは、文字起こしなしで進める。音声をインターネットのサービスに送る方法を使うかは、本人に聞いて決める。

## 4. やらないこと

- 音声・動画を、文字起こしのためにインターネットのサービスへ送らない（MLX Whisper を使えないときに、ほかの方法を使うかは本人に聞く）
- `~/.my-video-editor/` の外に、Python の部品を入れない（`pip install --user` や `sudo` は使わない）
- Homebrew など、ほかの道具を勝手に入れない（ffmpeg はこの道具の中に入っている）
