# 聞き取りの質問

このキットを使う人は、AI にもパソコンにもくわしくない人を想定している。
**質問は、相手が答えやすい順番で、1つずつ、かんたんな言葉で聞く。**

## 聞き方の決まり

- **1回に1問だけ聞く。** 相手が慣れてきて、答えがすぐ返ってくるようになったら2問まで。一度に全部並べない。
- **下の「聞く文」をそのまま使ってよい。** むずかしい言葉（パス・ディレクトリ・コーデック・フレームレートなど）は使わない。どうしても使うときは、すぐにかんたんな言葉で言いかえる。
- **場所を聞くときは、必ず「答え方の案内」も一緒に伝える。** 相手は「パス」を知らない前提で聞く。
- **相手にターミナルやコマンドを打たせない。** 調べものは自分（AI）が読み取りだけで行う。
- 編集の見た目や数値（文字の大きさ・色・テンポ・音量など）について、例・おすすめ・「ふつうは〜です」は添えない。相手の答えをそのまま使う。
- **相手が「わからない」「あとで」と言ったら、「未定」にして先へ進む。** あとで必要になったときに聞き直す。
- **相手がすでに言ったこと・`my-environment.md` に書いてあることは、聞き直さない。** 「前と同じ〇〇でよいですか？」と確かめるだけにする。
- 相手が「頼み方テンプレート」（`■` の見出しが並んだ文）で頼んできたら、うまっている欄は聞き直さない。`＜ここに場所を貼る＞` のまま残っている欄・「わからない」と書かれた欄だけを、下の質問で1つずつ聞く。

## 場所を聞いたあとに必ずやること

1. 貼られた場所が本当にあるかを、**読み取りだけで**確かめる。
2. その中のファイル名と数を見せて、「この中に〇本の動画と〇個の画像がありました。これで合っていますか？」と聞く。
3. 見つからないときは、相手を責めずに「その場所が見つかりませんでした。もう一度コピーしてもらえますか？」と、答え方の案内をもう一度伝える。

## 答え方の案内（場所を聞くときに毎回そえる文）

> 場所は、文字を打たなくてもコピーできます。
> 1. Finder で、そのフォルダ（またはファイル）を右クリックします
> 2. メニューが出たら、キーボードの option キーを押します
> 3. 「"〇〇"のパス名をコピー」をえらびます
> 4. ここに貼ってください（Command＋V）
> わからなければ「わからない」で大丈夫です。

## A. 最初の1回に聞くこと（いつもの置き場所。変わったら聞き直す）

上から順に1問ずつ聞く。

| # | 聞くこと | 聞く文（そのまま使ってよい） |
|---|---|---|
| A-1 | 使う編集ソフト | 「動画の編集には、どのソフトを使っていますか？ パソコンの中に、〇〇と〇〇が見つかりました。」（調べて見つかったソフトを並べて、えらんでもらう） |
| A-2 | 撮った素材のいつもの場所 | 「撮った動画や録った音は、いつもどのフォルダに入れていますか？」＋答え方の案内 |
| A-3 | 素材の使い方 | 「素材は、いまの場所のまま使いますか？ それとも、動画ごとに新しいフォルダを作ってコピーしてから使いますか？」 |
| A-4 | お手本（リファレンス）のプロジェクト | 「お手本にしたい、前に自分で作った編集のデータ（プロジェクトファイル）はありますか？ あれば、どこに置いてありますか？」＋答え方の案内。「なければ『なし』で大丈夫です」とそえる |
| A-5 | お手本の書き出した動画 | 「そのお手本の、できあがった動画（書き出した動画）もありますか？ あれば、どこにありますか？」＋答え方の案内 |
| A-6 | 新しいプロジェクトの保存先 | 「これから作る編集のデータ（プロジェクトファイル）は、どこに保存しますか？」＋答え方の案内 |
| A-7 | 書き出した動画の保存先 | 「できあがった動画は、どこに保存しますか？」＋答え方の案内 |
| A-8 | ファイル名のつけ方 | 「できあがった動画の名前に、いつも決まったつけ方はありますか？（なければ『なし』で大丈夫です）」 |
| A-9 | 毎回使うもの | 「BGM・効果音・ロゴ・文字のデザインなど、毎回使うものはありますか？ あれば、どこにありますか？」＋答え方の案内 |
| A-10 | テロップの原稿 | 「テロップ（字幕）の原稿を、いつもどこかに書いていますか？ あれば、どこにありますか？」＋答え方の案内 |
| A-11 | さわってほしくない場所 | 「さわってほしくないフォルダやファイルはありますか？」 |

- プロジェクトがファイルではなくソフトの中にしまわれている編集ソフト（DaVinci Resolve など）では、A-4・A-6 は「場所」ではなく「プロジェクトの名前」を聞く。どちらなのかは、ソフトのヘルプか画面で確かめてから聞く。

## B. 毎回の編集で聞くこと

すでにわかっていることは聞かない。上から順に1問ずつ。

| # | 聞くこと | 聞く文（そのまま使ってよい） |
|---|---|---|
| B-1 | 今回の素材一式 | 「今回使う素材は、どのフォルダに入っていますか？」＋答え方の案内。確かめたあと「この中の〇本ぜんぶを使いますか？」と聞く |
| B-2 | 今回のお手本 | 「今回のお手本は、いつもの〈A-4 の場所〉でよいですか？ ちがうお手本があれば、場所を教えてください。」 |
| B-3 | まねするところ | お手本があるとき:「お手本の、どこをまねしますか？ たとえば、テロップの位置・文字の大きさや色・カットのテンポ・BGM の入れ方などです。」（観点だけを示す。値は聞いて決める） |
| B-4 | どこに出す動画か・向き・長さ | 「できあがった動画は、どこに出しますか？ 横・縦・正方形のどれですか？ 長さのめやすはありますか？」 |
| B-5 | やってほしい作業 | 「編集ソフトで、今回やってほしいことを教えてください。3つくらいまでだと、とちゅうで止まりにくいです。」（相手が言った作業だけを手順表に入れる。足したほうがよさそうなものは「〜もしますか？」と聞くだけ） |
| B-6 | 作業ごとに決まっていること | 作業ごとに1つずつ:「〈作業〉は、どんなふうにしたいですか？」聞く観点: どこを残してどこを切るか／並べる順番／文字を入れるなら何を・どこに・どんな見た目で／音楽を入れるならどれを・どこに／色を直すならどう直すか |
| B-7 | テロップの原稿 | テロップを入れるとき:「テロップの文字は、原稿がありますか？ あれば、どこにありますか？ なければ、この Mac の中で動画の音声を文字にしてもよいですか？（音声はインターネットに送りません）」（MLX Whisper を使う。`references/transcribe-setup.md`。入っていなければ、入れてよいかを先に聞く） |
| B-8 | BGM・効果音 | 音を入れるとき:「使う BGM や効果音は決まっていますか？ どこにありますか？」＋答え方の案内 |
| B-9 | 今回のプロジェクトの保存先 | 「今回の編集のデータは、いつもの〈A-6 の場所〉に保存してよいですか？ 名前は何にしますか？」 |
| B-10 | とちゅうで見せるところ | 「とちゅうで、どこまで進んだら画面を見せましょうか？」 |
| B-11 | 書き出し | 「今回は、書き出し（1本の動画にすること）までやりますか？ やるなら、いつもの〈A-7 の場所〉でよいですか？ ファイルの名前と、形式や大きさで決まっているものはありますか？」 |

## C. 作業のあとに聞くこと

1. 「直したいところはありますか？」
2. 「直したところのうち、次からも同じようにしたいものはありますか？」（あれば `my-notes.md` に、相手の言葉のまま書く）
3. 置き場所が今回だけちがったときは「次からも、この場所を使いますか？」（はいなら `my-environment.md` を書き直して見せる）
